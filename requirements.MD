Minimal launcher
A minimalistic launcher for android phones based on lightphone.

See the designs in inspiration-design for how it should look.

Requirements: 
- A minimalistic dock where a user can launch apps
- The dock can have multiple vertical pages
- What apps are there the usere can select
- In the dock apps can be renamed (By default spotify is called music, google maps navigation)
- No app icons are shown
- The order of apps in the dock can be changed
- Swiping to the right from the dock opens a list with all apps, sorted alphabeticly
- Scrolling through the all apps an indicator shows at what letter the user is
- Swiping to the right from the dock shows the weath, current location and notifications. Clicking on notification goes to the app

The code should be commited to github(git@github.com:petervanmanen/minimalistlauncher.git) and a build should be available there
